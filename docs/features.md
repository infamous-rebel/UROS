# UROS Features

## Recruitment Pipeline

1. **Intake** — CV/CSV upload, email parsing, Bdjobs/Teletalk import, ATS webhook
2. **Eligibility** — Deterministic rule evaluation against rule packs
3. **Dimension Scoring** — 7-dimension candidate matching (merit, diversity, geography, etc.)
4. **Ranking** — Weighted composite scoring with knockout rules
5. **HIL Gates** — Human-in-the-loop review for borderline candidates
6. **Verification** — Document verification, reference checks, fraud detection
7. **Onboarding** — Selected candidate onboarding workflow
8. **Offboarding** — Rejected/withdrawn candidate exit management

## Assessment

- **MCQ Scanner** — Paper-based MCQ answer sheet OCR scanning
- **Digital Exam Creator** — No-code exam paper builder with question banks
- **7-Dimension Matching** — Multi-axis candidate evaluation scorecard

## Quality & Verification

- **Fraud Detection** — Inconsistency detection across candidate documents
- **Reference Checks** — Automated reference collection and verification
- **Verification Center** — Central hub for all verification statuses

## People Management

- **Onboarding** — New hire onboarding checklist and document collection
- **KPI Scores** — Recruitment process performance metrics
- **Departmental Personas** — Role-based departmental staffing profiles
- **Improvement Advisor** — AI-assisted process improvement recommendations
- **Task Logs** — Agent and human task tracking
- **Offboarding** — Exit management and talent pool re-engagement

## Analytics

- **Recruitment Analytics** — Funnel analysis, source effectiveness, timeline metrics
- **Report Generator** — PDF/Excel/CSV export with preview
- **Candidate Rediscovery** — Talent pool re-engagement from past candidates

## Administration

- **Brain Studio** — No-code rule pack editor with conflict detection, version history, simulation
- **Appeals** — Candidate appeal triage and resolution
- **Audit Stream** — Real-time audit log viewer
- **Settings** — 12 sub-tabs: Profile, Credentials (BYOK), SMS Fallback, Backup, Audit, Data Export, etc.

## Cross-Cutting

- **i18n** — Full English + Bangla (বাংলা) support with 890+ keys
- **Command Palette** — Cmd+K quick navigation
- **Dark Mode** — System-aware theme (planned)
- **RBAC** — Role-based access control (ADMIN, RECRUITER, AUDITOR, VIEWER)
- **Multi-tenancy** — Organization-scoped data isolation
