# i18n — Internationalization Foundation

## Status
Part 10 (Quest 05) — Full i18n scaffold complete.

## Architecture

### Single Source of Truth
- `src/ui/src/i18n/en.json` — English translations (304 keys)
- `src/ui/src/i18n/bn.json` — Bengali translations (304 keys)
- Key parity enforced: every key in `en` exists in `bn` and vice versa

### Translation Function
```tsx
import { useI18n } from "../i18n";
const { t, language, setLanguage } = useI18n();
t("dashboard.title") // → "Dashboard" (en) or "ড্যাশবোর্ড" (bn)
t("queue.selected", { count: 5 }) // → "5 selected" (en) or "৫টি নির্বাচিত" (bn)
```

### Format Helpers (`src/ui/src/lib/format.ts`)
- `formatDate(date, locale)` — locale-aware date via `Intl.DateTimeFormat`
- `formatNumber(num, locale)` — locale-aware number via `Intl.NumberFormat`
- `formatCurrency(amount, currency, locale)` — locale-aware currency
- `formatPhone(phone, locale)` — Bangladeshi format: +880 1X XXXX-XXXX
- `formatRelativeTime(date, locale)` — "5 minutes ago" / "৫ মিনিট আগে"

## RTL Readiness

### Current State
- `<html dir="ltr">` set in `index.html`
- CSS uses Tailwind utility classes (mostly directional: `ml-`, `pr-`, `left-`, etc.)
- No full RTL layout yet — scaffold is in place for future `dir="rtl"` swap

### Guidelines for New Code
When writing new CSS/Tailwind:
- Prefer logical properties: `ms-2` (margin-inline-start) over `ml-2` (margin-left)
- Prefer `ps-2` (padding-inline-start) over `pl-2`
- Prefer `start-` / `end-` over `left-` / `right-` for positioning
- Flex `gap` is direction-agnostic — prefer it over margin hacks
- Existing directional classes will need a sweep before RTL activation

## Language Switcher
- Persisted in `localStorage` key `uros_ui_language`
- Switching updates immediately without page reload (React context)
- Applies to: labels, buttons, tooltips, table headers, form labels, empty states, error messages, toasts, time-ago strings
