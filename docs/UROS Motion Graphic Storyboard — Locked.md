
# UROS Motion Graphic Storyboard — Locked

## Purpose

A 15–20 second, silent, loopable flat 2D vector animation for the landing page hero. It must teach the UROS concept in seconds with no audio.

## Style

-   Flat 2D vector
-   Subtle motion
-   No frantic movement
-   Calm, clear, explainable

## Scene 1: The Problem

-   Visual: A huge wall of paper CVs (thousands)
-   A few small human figures trying to sort them
-   Visual clutter, red warning flashes
-   Message: Manual screening is overwhelming.
-   Dominant color: Muted red / gray

## Scene 2: UROS Appears

-   Visual: The wall condenses into structured rows
-   Agents appear as labeled modules: Intake, Parser, Eligibility, Scoring
-   Teal color for agents
-   Message: UROS brings structure.
-   Dominant color: Deep teal

## Scene 3: The Pipeline

-   Visual: Applications flow through horizontal pipeline
-   Each agent highlights and processes a batch
-   Status pills appear: Auto-Pass (green), Auto-Fail (red), Needs Review (amber)
-   Message: Deterministic rules evaluate every candidate.
-   Dominant color: Deep teal

## Scene 4: Human-in-the-Loop

-   Visual: Zoom into Needs Review queue
-   A human cursor clicks Approve or Override
-   Terracotta color for human action
-   Message: Humans decide. Agents recommend.
-   Dominant color: Terracotta

## Scene 5: Audit & Trust

-   Visual: Transparent ledger scrolls behind pipeline
-   Every action drops into audit log as line item
-   Checkmarks: Traceable. Explainable. Fair.
-   Message: Nothing is hidden.
-   Dominant color: Off-white / slate

## Scene 6: Ownership

-   Visual: API key slots, local server icon, budget control
-   Message: Your keys. Your rules. Your system.
-   Dominant color: Terracotta / amber

## Scene 7: Final

-   Visual: UROS logo with tagline
-   CTA button fades in
-   Message: Recruitment at Scale. Trust at Every Step.
-   Dominant color: Deep teal + terracotta

-   Open hexagon or open box
-   Small human icon at center
-   Teal for structure, terracotta for human judgment
